General

Appearance

Changes show straight away in the sidebar, top bar and start page, so you can watch them as you go.

Each Space keeps its own colours or gradient (up to 3 colours). For any colour: the pencil next to the Space name › Edit theme color.

Transparency lets your desktop show through the sidebar and top bar, blurred (Windows 11). Web pages always stay solid.

A theme file holds these appearance, top bar, sidebar and start page settings plus this Space’s colours. Importing one asks before changing your Space’s colours, and can be undone.

Top bar

Drag buttons between the boxes to show, hide or reorder them (or focus one and use the arrow keys). Right-click the top bar for quick options.
